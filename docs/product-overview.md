# Sansyar product overview

Sansyar is a Persian RTL sports venue reservation platform for customers, venue owners, staff, and super admins.

## MVP scope

- Customer discovery, filtering shell, venue cards, available slots, booking CTA, wallet surface, and PWA installation.
- Owner/admin operational panel with dashboard, calendar, bookings, finance, reviews, approvals, and settings navigation.
- Echo + MongoDB API with auth/RBAC, sports, complexes, halls, slots, bookings, payments, wallet, reviews, finance placeholders, seed data, and map endpoint.
- Safe booking foundation: atomic slot status update, active booking unique index, idempotency keys, and strict status names.

## Future scope

- Real payment gateway adapters and verified webhook state machines.
- Real SMS provider adapter and scheduled reminder worker.
- Object storage for image upload.
- Full moderation, settlement exports, staff subaccounts, and richer leaderboards.
- Deep GIS clustering, route ETA, and user geolocation permissions flow.
